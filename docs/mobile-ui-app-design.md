# CC Remote 手机端 UI 设计规范

## 当前方向

手机端采用浅色活力控制台。它不是聊天机器人皮肤，也不是监控仪表盘。界面需要有艺术感和辨识度，同时让连接、任务、权限和输入始终容易理解。

当前代码是真实设计源。外部参考图和早期 Figma 草稿不再作为实现约束。

## 视觉语言

整体使用黑白骨架与三种活力色。背景是暖纸色，主体文字和轮廓使用近黑色。薄荷绿表示连接、可用和进行中。亮黄用于强调、层叠阴影和少量高光。珊瑚色用于停止、错误和需要注意的状态。

主题令牌位于 `mobile/lib/signal_console_theme.dart`。主要颜色是 `ink #14130F`、`mint #54E6B1`、`yellow #FFD84A`、`coral #FF786B`、`porcelain #FFFDF5`。界面不使用蓝紫渐变、通用玻璃拟态和灰白卡片堆叠。

轮廓是设计的重要组成。主面板使用 1.6 到 1.8 像素黑色描边，搭配无模糊的彩色偏移阴影。圆角大而明确。状态标签使用胶囊，普通按钮和输入控件保持较小圆角。局部允许切角，让部件更像编辑插画，而不是系统设置页。

字体使用圆润系统无衬线字体，并提供中文字体回退。标题短而有力度，正文保持正常阅读密度。模型、路径、token 数和代码使用紧凑排版，不能抢过任务内容。

## 页面结构

App 只有启动判定、扫码配对和主控制台三条主路径。项目与会话、工作区和设置使用 sheet 或抽屉，不增加底部 Tab。

背景由暖纸色底和少量大色块组成。色块只建立画面节奏，不承载信息。页面中的信息部件必须有清晰的前后层级，避免所有内容都变成同等权重的卡片。

## 扫码配对页

配对页的标题是让手机找到电脑。上方保留一个小型终端角色，用来增加亲和力，但它不能代替信息，也不能占据大面积空间。

扫描框使用黑色轮廓、亮黄偏移阴影和明显圆角。相机区域是页面主视觉。下方状态卡显示等待二维码、配对中、需要重试和重新扫描。识别二维码后先打开确认 sheet，展示电脑名、origin 和二维码有效状态，确认后才换取 token。

横屏或低高度设备进入紧凑布局，扫描区缩短，整页允许滚动。错误不能把用户锁在失效的扫码状态，重新扫描必须始终可达。

## 主控制台

主控制台由顶部连接舱、中央 transcript 和底部 Command Dock 组成。

顶部连接舱采用紧凑双栏。左侧只显示状态标签和一行当前状态标题。右侧第一行放项目与会话、工作区、新对话和设置四个操作，下面右对齐显示目录与电脑名，再显示模型和剩余上下文。正常高度下最小高度约 84 像素，键盘弹出或小屏时进入固定 84 像素紧凑模式。

顶部不再展示大型黑色角色。角色只保留在扫码页和 transcript 的小头像中。目录、模型和上下文属于辅助信息，应靠右、缩小并在空间不足时截断或缩放，不能迫使连接舱继续增高。

连接状态使用短文案。已连接时显示已经准备好了，运行中显示正在处理这件事，离线时显示等电脑回来。状态和修复动作放在同一视区，避免用户到处寻找重新连接。

中央 transcript 保留对话可读性，但不复制普通聊天 App。用户消息靠右，使用浅薄荷色块。Claude 回复靠左，使用小头像、Markdown 正文、轻量瓷白气泡和边框。思考与工具活动沿纵向任务轨出现，任务结束后只保留有价值的最终内容。

空 transcript 不做营销欢迎页。离线时优先把重新连接卡放在顶部。在线时只给少量可填入输入框的任务建议。

底部 Command Dock 使用近黑色实体面板和珊瑚色偏移阴影。第一行显示权限模式、连接或传输状态和信号轨。第二行承载附件入口、输入框和发送按钮。运行时发送按钮替换为珊瑚色停止按钮，停止中禁用重复点击并显示进度。

## 功能部件

权限模式使用胶囊入口和底部选择 sheet。`bypassPermissions` 必须使用警告色，选择后显示二次确认，并只对下一次任务生效。

附件在发送前以横向短卡显示，图片使用缩略图，普通文件使用文件图标。上传时禁止切换会话。单轮最多 5 个附件，单个文件最大 25MB。

项目与会话面板负责切换已注册项目、恢复会话和新建会话。工作区抽屉负责只读文件、Git 变更和 diff。设置 sheet 只放通知、重连和退出配对等设备级动作。

## 动效与反馈

按钮按压反馈约 90 毫秒，普通状态切换约 160 到 220 毫秒。信号轨可以持续运动，思考状态可以显示动画和计时，其余部件不做无意义循环动画。

系统开启减少动态效果时，路由和连续动画应关闭或降级。键盘出现时顶部进入紧凑模式，指令建议限制在键盘上方，不允许遮挡输入区。

## 响应式和文字

设计基准是单手竖屏，但必须覆盖小屏、横屏、键盘弹出和系统大字体。连接舱对设备文字缩放进行上限控制，正文仍尊重可访问性缩放。所有辅助信息需要设置单行、截断或 `FittedBox`，避免 RenderFlex overflow。

中文必须使用真实系统字体验证。Flutter golden 测试里的 Ahem 字体只能验证几何，不能代表真机中文字形。

## 验收标准

用户打开主界面后能立刻看到连接状态、当前任务和发送入口。顶部不能抢占对话空间。运行中停止按钮始终可见。离线时旧 transcript 保留，重新连接动作清楚。项目、目录、模型和上下文可查，但不会盖过当前任务。

界面如果重新变成灰白工具面板、卡片套卡片、巨型吉祥物或普通聊天 App，就偏离了当前方案。
